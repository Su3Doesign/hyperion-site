# Hyperion GEN.2 — landing page sections and headline ideas

The live site uses the first option in each section (marked **live**). The others are tested
alternatives in the same voice: plain, specific, engineering-minded, no hype words.

Voice rules: short declarative sentences; real numbers over adjectives (4,629 mm, 100°, 72,000 blades);
the car is a design study, never "the fastest" or "revolutionary"; the studio speaks as "we" only in
the contact section.

---

## 1. Hero — the name behind the car

Job: say what this is in one line, show the car, show who made it.

| Headline | Note |
|---|---|
| **A hypercar that was never built, engineered as if it would be.** | live |
| Built to the last bolt. Never built at all. | sharper, more playful |
| One car. Designed, modelled and rebuilt by one person. | puts the maker first |
| Hyperion. A design study with nothing left to imagine. | for a short social cut |

Support line (live): "Designed and modelled by Sumanth Richie. Every panel, hinge and light, down to an
engine nobody would ever see."

Spec strip: Length 4,629 mm · Width 2,220 mm · Height 1,150 mm · HC-8 4.0 L V8.
